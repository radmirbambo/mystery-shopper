# Mystery-shopper для стоматологий

Измеряет, за сколько минут клиника перезванивает по заявке с сайта. Всё работает на твоём Маке, VPS не нужен.

| Часть | Что делает |
|---|---|
| `formbot/` | Оставляет заявку на сайте клиники твоим именем и мобильным, фиксирует время в бэкенде |
| `server/` | SQLite + FastAPI на 127.0.0.1:8000: заявки, перезвоны, дельта, отчёт `/report.xlsx` |
| `telegram/` | Бот @secretshopperdental_bot: после звонка пишешь название клиники — он записывает перезвон и считает дельту |
| `discover/` | Поиск новых клиник: OSM → `data/candidates.csv` → отсев сайтов → перенос в `clinics.csv` |
| `voximplant/` | Голосовой агент. **Не используется** (нужна усиленная ЭП для покупки номера), код оставлен на будущее |

## Как работает день
1. Бэкенд и бот крутятся в фоне через launchd (`launchd/*.plist`, логи в `logs/`). Ставятся один раз:
   `cp launchd/*.plist ~/Library/LaunchAgents/ && launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.mystery-shopper.backend.plist` (то же для `.bot`).
2. Заявки: `./run.sh formbot --dry` (проверить скриншоты), затем `./run.sh formbot` — перед каждой отправкой ждёт Enter.
   Сайты с капчей/без формы делаешь руками и фиксируешь: `curl -X POST -H "X-Token: $MS_TOKEN" 127.0.0.1:8000/form-submitted -d '{"clinic_id": N}'`.
3. Клиника перезвонила на твой мобильный → отвечаешь сам, узнаёшь название, пишешь боту:
   `Легенда` (время = время сообщения), `Легенда 14:35` (записал позже), `Легенда wa` (написали в WhatsApp), `?` (не понял, кто).
   Если бот не уверен, предложит 3 варианта — ответь цифрой.
4. `/pending` — кто ещё не перезвонил, `/report` — Excel в чат.

## Автономный режим (цель — Радмир только отвечает на звонки)
- `daily.sh` по будням в 12:00 (launchd `com.mystery-shopper.daily`): берёт 25 очередных ok-кандидатов + проверенные 12,
  оставляет заявки `--auto --headless`, Луиза присылает отчёт «отправлено N, ждём звонков от …».
  Включить: `cp launchd/com.mystery-shopper.daily.plist ~/Library/LaunchAgents/ && launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.mystery-shopper.daily.plist`
  Пауза/возобновление — `/pause`, `/resume` Луизе (флаг `data/PAUSE`); `/wave` — волна прямо сейчас.
  Репетиция без отправки и без сообщений: `MS_DRY=1 MS_QUIET=1 ./daily.sh`. После волны фоном собираются карточки ЛПР.
- `digest.sh` по будням в 9:00 (launchd `com.mystery-shopper.digest`): Луиза присылает, кто не перезвонил за сутки,
  кто перезвонил дольше 30 мин, кто быстрый.
- Модель для разбора звонков, имён с сайтов и подбора форм — ЛОКАЛЬНАЯ: Qwen2.5-3B-Instruct 4-bit через `mlx_lm.server`
  (launchd `com.mystery-shopper.llm`, порт 8080, `calls/models/`). Настройка в `local.env`: `MS_LLM_BASE`, `MS_LLM_MODEL`.
  Бесплатно и без лимитов; ~8–10 с на запрос на M1. Запасной вариант — OpenRouter (`MS_LLM_BASE=https://openrouter.ai/api/v1`,
  ключ `OPENROUTER_API_KEY`), у бесплатных моделей там дневной лимит, после 429 модули молчат 15 минут (`data/llm_guard.py`).
- Сайты с капчей: `./run.sh formbot --assist --ids …` — открытый браузер, бот заполняет, ты только решаешь капчу (5 с на сайт).
- Что не осилил ни бот, ни assist: `/next` Луизе — пачка ссылок, заявку оставляешь руками, отвечаешь «готово 1 3».
- formbot умеет: LLM-подбор формы через OpenRouter, формы в iframe, принудительное раскрытие модалок, JS-ввод телефона.
  Сайты, отдающие 403 headless-браузеру (анти-бот), автоматике недоступны.

## Запись звонков → транскрипт → разбор (`calls/`)
iPhone (iOS 18.1+, регион США): кнопка записи в начале звонка → Заметки → iCloud → Мак. `calls/watch_notes.py`
(launchd `com.mystery-shopper.calls`, раз в 2 мин) находит новый аудиофайл, `pipeline.py` транскрибирует локально
(mlx-whisper, large-v3-turbo, русский), модель через OpenRouter оценивает администратора (имя, предложение, запись,
тон, оценка 0–10, цитаты, резюме), всё уходит в `POST /transcript` и привязывается к перезвону по клинике или времени
(±20 мин). Луиза присылает разбор. Запасной канал: переслать запись Луизе — тот же конвейер.
Руками: `./run.sh call file.m4a [--clinic-id N]`.

## ЛПР и карточка лида (`discover/lpr.py`)
`./run.sh lpr --ids 6,7` или `--measured`: обход сайта (о клинике/контакты/команда/лицензии/политика) → ИНН, ОГРН,
почты, телефоны, люди с должностями (модель по фрагментам вокруг «главный врач/директор/…») → DaData по ИНН
(`DADATA_TOKEN` в local.env: юрлицо, руководитель, статус) → `POST /lpr`. Луиза: `/lead Легенда` — замер + ЛПР +
разбор разговора + черновик письма. В `report.xlsx` добавлены оценка, администратор, разбор, руководитель, почты.

## Пополнение списка клиник
Источник — OpenStreetMap (бесплатно, данные можно хранить; Яндекс Геопоиск запрещает сохранять результаты, 2ГИС платный).
```
./run.sh discover           # все стоматологии Москвы с сайтом → data/candidates.csv (одна строка на домен, сети схлопнуты)
./run.sh triage             # сухой прогон formbot по каждому сайту: ok | captcha | no_form | mask_fail | dead; фоном ~1.5 ч
./run.sh promote --n 30     # очередные 30 ok (сначала с имплантацией) → clinics.csv, рестарт бэкенда, печатает id для formbot
```
`triage` пишет построчно, его можно прерывать; повторный `discover` не трогает уже отсеянных.

Секреты в `local.env` (шаблон `local.env.example`), загружает `run.sh`.

## Старый вариант с голосовым агентом Voximplant (не используется)

**1. Бэкенд (10 минут).** На VPS (нужен https — Caddy/nginx или Cloudflare Tunnel):
```
cd server && pip install -r requirements.txt
export MS_TOKEN=$(openssl rand -hex 16)
uvicorn app:app --host 0.0.0.0 --port 8000
```
Проверка: `curl -H "X-Token: $MS_TOKEN" https://host/report` → `summary` с нулями.

**2. Voximplant (30 минут).** Купить московский номер, создать приложение, вставить `voximplant/scenario.js`,
заменить `BACKEND` и `TOKEN`, привязать сценарий к номеру правилом маршрутизации. Проверить тестовым звонком
со своего мобильного: в `/report` должна появиться строка `matched_by: none` с твоим номером, в логах — транскрипт.
Имена `ASRProfileList.Yandex.ru_RU` / `VoiceList.Yandex.ru_RU_alena` сверить с текущей документацией — их иногда переименовывают.
Дополнительно: привязать к этому же номеру WhatsApp — часть клиник пишет вместо звонка; такие фиксируешь руками через `POST /manual`.

**3. Заявки (вечер, 19:00–20:30 — самое показательное время).**
```
cd formbot && pip install -r requirements.txt && playwright install chromium
export MS_BACKEND=https://host/ MS_TOKEN=... MS_NAME="Радмир" MS_PHONE="+7 9XX ..."   # номер Voximplant
export ANTHROPIC_API_KEY=...     # для страниц, где форма нестандартная
python fill_forms.py --dry       # сначала прогон без отправки: смотришь screenshots/, что формы найдены правильно
python fill_forms.py             # боевой прогон; перед каждой отправкой ждёт Enter
```
Сайты с капчей и без формы бот помечает `skipped` в `formbot_log.csv` — их оставляешь руками и фиксируешь
`curl -X POST .../form-submitted -d '{"clinic_id": N}'`.

**4. Отчёт.** `GET /pending` — кто ещё не перезвонил и сколько минут прошло. `GET /report.xlsx` — таблица для писем:
у каждой клиники время заявки, время перезвона, дельта, транскрипт разговора.


### Что агент говорил бы по телефону
Caller ID совпал → «Да, оставлял. Спасибо, что перезвонили. Я пока сравниваю несколько клиник, наберу сам». 
Не совпал → «Заявок у меня несколько, подскажите, из какой вы клиники?» → ответ → прощание.
Агент никогда не записывается на приём: пустой слот в расписании клиника запомнит, и тёплое письмо станет претензией.

## Границы
- Одна заявка на клинику, бэкенд не даст оставить вторую.
- Капчи не обходим — такие сайты делаешь руками.
- Данные только твои (имя, номер). ЛПР потом честно говоришь: «я тестировал вашу скорость перезвона — вот время».
